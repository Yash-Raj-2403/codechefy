<h2><a href="https://www.codechef.com/practice/course/cpp/PCPP03/problems/CBSPEED?tab=statement">Chef and Brain Speed</a></h2><h4>Difficulty: </h4><p>In ChefLand, human brain speed is measured in bits per second (bps). Chef has a threshold limit of <span class="math math-inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>X</mi></mrow><annotation encoding="application/x-tex">X</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.6833em;"></span><span class="mord mathnormal" style="margin-right: 0.07847em;">X</span></span></span></span></span> bits per second above which his calculations are prone to errors. If Chef is currently working at <span class="math math-inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>Y</mi></mrow><annotation encoding="application/x-tex">Y</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.6833em;"></span><span class="mord mathnormal" style="margin-right: 0.22222em;">Y</span></span></span></span></span> bits per second, is he prone to errors?</p><p>If Chef is prone to errors print <code>YES</code>, otherwise print <code>NO</code>.</p><div class="notranslate">
<h3>Input Format</h3>
<p>The only line of input contains two space separated integers <span class="math math-inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>X</mi></mrow><annotation encoding="application/x-tex">X</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.6833em;"></span><span class="mord mathnormal" style="margin-right: 0.07847em;">X</span></span></span></span></span> and <span class="math math-inline"><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>Y</mi></mrow><annotation encoding="application/x-tex">Y</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height: 0.6833em;"></span><span class="mord mathnormal" style="margin-right: 0.22222em;">Y</span></span></span></span></span> — the threshold limit and the rate at which Chef is currently working at.</p>
</div><div class="notranslate">
<h3>Output Format</h3>
<p>If Chef is prone to errors print <code>YES</code>, otherwise print <code>NO</code>.</p>
<p>You may print each character of the string in uppercase or lowercase (for example, the strings <code>yes</code>, <code>Yes</code>, <code>yEs</code>, and <code>YES</code> will all be treated as identical).</p>
